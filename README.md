# Catálogo mayorista con precio del día — demo de Vonoa

Demo para joyeros de mayoreo: el joyero captura el precio del gramo (oro 10k, 14k, plata .925)
una vez al día, todo el catálogo se recalcula, el cliente arma su pedido y lo manda por WhatsApp
ya armado. Incluye certificado con QR por pieza (`c.html?p=ID`).

Piezas y precios **de ejemplo** (`piezas.js`), no son de ninguna joyería real. `noindex`.
Publicado en https://vonoaweb.github.io/joyeria-mayoreo-demo/
